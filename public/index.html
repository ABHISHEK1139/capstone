Why Standalone?

              
Scikit-learn core excludes frequent-pattern mining. skarm implements BaseEstimator, TransformerMixin, clone(), Pipeline, GridSearchCV, and sparse SciPy CSR matrices cleanly as an independent package.

            

            

              
25-Corpus Proof

              
1,650 benchmark trials across 8 domains (Kosarak 990k rows, Accidents, BMS-POS, Adult Census, Online Retail): 157/157 exact engine pairs + 25/25 external Java SPMF / mlxtend parity (Δsupp = 0.0).
